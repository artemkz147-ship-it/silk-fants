# Шёлковые фанты (Silk Fants)

> **18+ / NSFW** — карточная игра фантазий для пар. Только для взрослых.

Только для пары **мужчина + женщина**. Колода **CoupleDares**: **520** заданий на **4 уровня** (Флирт → Петтинг → Жар → Максимум). Загружается из `assets/tasks.json` в рантайме.

**Package:** `com.artemkz.silkfants`  
**minSdk 26 · targetSdk 34 · Kotlin + Jetpack Compose**  
**Версия:** 0.3.0

## Возможности

- Возрастной гейт 18+ при первом запуске (DataStore)
- Главное меню: Тянуть фант / Все задания / Правила / О игре
- 520 заданий CoupleDares, уровни 1–4
- Фильтр «кто выполняет»: Мужчина / Женщина / Для вас двоих (actorSex M/F/U)
- Плейсхолдеры `{p_nom|gen|dat|acc|ins}` → партнёр / партнёрша
- Сессия: перемешивание пула, без повторов до конца или сброса
- Карточка на экране игры **без скролла**: компактная иллюстрация + AutoSizeText
- Иллюстрации `fant_01`…`fant_50.webp` (hash id → 1..50)
- Портретный режим, русский интерфейс, тёмный шёлково-розовый UI

## Как скачать APK

Релизы: [Releases](../../releases).

### Вариант 1 — GitHub Release

Скачайте `app-debug.apk` с тега `v0.3.0`.

### Вариант 2 — артефакт Actions

1. Откройте вкладку [Actions](../../actions).
2. Выберите успешный workflow **Android CI**.
3. Скачайте артефакт **`silk-fants-debug-apk`**.

## Установка из исходников

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Нужны JDK 17 и Android SDK (compileSdk 34).

## Правила контента

- Только для взрослых 18+
- Согласие и стоп-слово обязательны
- Уровни 3–4 включают проникновения и острые практики — выбирайте осознанно
- Задания с `seconds != 0` рассчитаны «до сигнала таймера»

## Ограничения

- Debug APK **не подписан** release-ключом (для личного использования / sideload).
- Нет онлайн-функций, рекламы и покупок.
- Арты лежат в `app/src/main/res/drawable-nodpi/fant_XX.webp`.
