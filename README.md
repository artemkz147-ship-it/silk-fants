# Шёлковые фанты (Silk Fants)

> **18+ / NSFW** — карточная игра фантазий для пар. Только для взрослых.

Тяните случайные задания из колоды из 50 мягких эротических фантов. Без проникновения: поцелуи, массаж, раздевание, дразнилки, ролевая игра, внешние игрушки.

**Package:** `com.artemkz.silkfants`  
**minSdk 26 · targetSdk 34 · Kotlin + Jetpack Compose**  
**Версия:** 0.1.0

## Возможности

- Возрастной гейт 18+ при первом запуске (DataStore)
- Главное меню: Тянуть фант / Все задания / Правила / О игре
- Колода из 50 уникальных заданий (интенсивность 1–3)
- Сессия: перемешивание, без повторов до конца колоды или сброса
- Выбор, кто выполняет: Партнёр А / Партнёр Б / для вас двоих
- Фильтр заданий по интенсивности
- Портретный режим, русский интерфейс, тёмный шёлково-розовый UI
- Иллюстрации ко всем 50 фантам (`fant_01`…`fant_50.webp`)

## Как скачать APK

Релизы: [Releases](../../releases).

### Вариант 1 — GitHub Release

Скачайте `app-debug.apk` с тега `v0.1.0` (после публикации тега).

### Вариант 2 — артефакт Actions

1. Откройте вкладку [Actions](../../actions).
2. Выберите успешный workflow **Android CI**.
3. Скачайте артефакт **`silk-fants-debug-apk`**.

## Установка из исходников

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Нужны JDK 17 и Android SDK (compileSdk 34).

## Правила контента

- Только для взрослых 18+
- Согласие и стоп-слово обязательны
- В этой колоде **нет проникновения** (ни PIV, ни анального, ни орального)
- Мягкая эротика: поцелуи, массаж, раздевание, дразнилки, внешние ласки

## Ограничения

- Debug APK **не подписан** release-ключом (для личного использования / sideload).
- Нет онлайн-функций, рекламы и покупок.
- Арты лежат в `app/src/main/res/drawable-nodpi/fant_XX.webp`.
